# 📌 About

**Neuro-Fusion Integrated Disease Prediction & Clinical Intelligence
System** is a unified AI healthcare platform integrating Machine
Learning, Deep Learning, Explainable AI (XAI), NLP and
Retrieval-Augmented Generation (RAG).

## 🌟 Modules

-   💡 Disease Prediction & Medical Recommendation
-   💊 AI-Powered Drug Recommendation
-   ❤️ Heart Disease Risk Assessment
-   🧠 Brain Tumor Detection
-   🤖 Medibot (LLM + RAG)

------------------------------------------------------------------------

# 🚀 Features

## 💡 Disease Prediction & Medical Recommendation

Predicts diseases from symptoms using a Random Forest model and provides
personalized healthcare guidance.

-   Disease prediction
-   Description
-   Precautions
-   Medication suggestions
-   Diet recommendations
-   Treatment guidance

## 🧠 Brain Tumor Detection

A transfer-learning based MRI classification system built using
**VGG16**, **Squeeze-and-Excitation Attention**, and **Grad-CAM
Explainable AI**.

-   Detects Glioma, Meningioma, Pituitary, No Tumor and Other
-   VGG16 Transfer Learning
-   SE Attention
-   Two-stage fine tuning
-   Grad-CAM visualization
-   Confidence score & probabilities
-   \~98% Accuracy
